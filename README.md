# YOUR NEXT STEP: TEST-PERSONALIDAD-MUNICH

## Descripción del proyecto

YOUR NEXT STEP es una aplicación web interactiva que permite a los usuarios descubrir qué estilo de zapatillas se adapta mejor a su personalidad mediante un test de preferencias. A partir de sus respuestas, la aplicación determina un perfil y ofrece una recomendación acorde con sus características.

## Funcionalidades principales

- **Test de personalidad:** cuestionario interactivo basado en las respuestas del usuario.
- **Clasificación de perfiles:** identificación de cuatro estilos: Urban, Sport, Classic y Bold.
- **Recomendaciones personalizadas:** selección de un perfil de zapatillas en función de las respuestas obtenidas.
- **Contenido visual:** incorporación de imágenes para ilustrar las preguntas y los resultados.
- **Interfaz de usuario:** diseño orientado a facilitar la navegación y la interacción con la aplicación.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño visual y presentación de los elementos.
- **JavaScript:** lógica del cuestionario, procesamiento de las respuestas y presentación de los resultados.

## Instalación y ejecución

La aplicación puede ejecutarse localmente sin necesidad de instalar dependencias adicionales.

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Acceder al directorio del proyecto.
3. Abrir el archivo `index.html` en un navegador web.
4. Completar el cuestionario para visualizar el resultado y la recomendación correspondiente.

Sustituir `URL_DEL_REPOSITORIO` por la dirección del repositorio de GitHub.

## Objetivo del proyecto

El objetivo de YOUR NEXT STEP es desarrollar una experiencia digital que combine moda, personalización y desarrollo web, facilitando la elección de zapatillas a través de un cuestionario interactivo.

Asimismo, el proyecto permite aplicar conocimientos de HTML, CSS y JavaScript mediante la creación de una aplicación web estructurada e interactiva.
